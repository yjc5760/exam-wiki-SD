考題編號：SD-2014-4

主分類： SD-U3-1 結構耐震設計 副分類： SD-U3-2 隔減震原理 分析方法： 概念題（消能系統比較 + 規範論述） 標籤： 被動消能 BRB 挫屈束制支撐 液態黏滯阻尼器 速度型元件 位移型元件 耐震補強 等值線性分析 三種變位情況 最大速度情況 最大變位情況 最大加速度情況 消能減震設計規範

1. 原始題目重述 (Problem Restatement)

題(一)（10分）： 說明「挫屈束制消能元件」（BRB, Buckling-Restrained Brace）及「液態黏滯消能元件」作為建築結構耐震補強時之優缺點。

題(二)（10分）： 含速度型元件之建築物的等值線性分析中，規範規定建築物內構材的設計力需考慮三個不同變位情況——最大變位情況（Δ_D）、最大速度情況（V_D）、最大加速度情況（A_D）——來計算，並採用最大值進行設計。請說明其原因。

2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

核心觀念：

  • BRB（位移型）：靠材料降伏消能，力學行為明確，但改變結構剛度與週期
  • 液態黏滯阻尼器（速度型）：靠黏滯阻力消能，消能力與速度相關，不增加結構剛度
  • 兩者消能機制不同 → 對結構的影響不同 → 各有適用場合
  • 速度型元件在最大位移時阻尼力接近零、在最大速度時阻尼力最大 → 三種時刻的內力分佈差異顯著 → 不能只取一種情況設計

出題者意圖： 測驗考生對被動消能元件力學行為的深度理解，以及對規範「三種變位情況」規定背後物理邏輯的掌握。

3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

題(一)核心比較架構

面向 BRB（位移型） 液態黏滯阻尼器（速度型）
消能機制 鋼材受拉壓降伏（滯回面積） 黏滯流體擠壓（F = Cv^α）
力-位移 矩形遲滯迴圈 椭圓形遲滯迴圈
相位關係 阻尼力與位移同相 阻尼力與位移差 90°
剛度貢獻 顯著增加側向剛度 不增加側向剛度

題(二)三種情況的物理根據

速度型阻尼器（F = Cv^α）的阻尼力與位移不同相：

  • 最大位移時：速度 ≈ 0 → 阻尼力 ≈ 0，但彈性變形力最大
  • 最大速度時：位移 ≈ 0 → 阻尼力最大，但彈性力較小
  • 最大加速度時：慣性力最大（F = ma），主要來自高階模態貢獻

因此，不同構材在不同時刻可能達到設計最大力 → 必須三種情況均檢核。

關鍵陷阱：

  • 題(一)不能只列條文，需說明消能機制本身（降伏 vs. 黏滯）導致優缺點
  • 題(二)不能只說「規範規定要這樣做」，需解釋物理上為何三個時刻的控制力不同

4. 步驟化詳細計算過程（論述題）

題(一)（10分）：BRB 與液態黏滯消能元件的優缺點

(A) 挫屈束制支撐（BRB）

消能機制： BRB 由芯材（鋼板）承受軸力，外包混凝土或鋼管作為挫屈束制裝置。在反覆地震荷載下，芯材拉壓均能降伏，產生矩形遲滯迴圈，每個循環消散能量 ≈ 4F_y·δ_y（面積）。

優點：

  1. 拉壓對稱的穩定消能行為 傳統斜撐受壓時挫屈失效，只能受拉消能（軟化遲滯迴圈）。BRB 在拉壓方向均能充分降伏，遲滯迴圈飽滿穩定，消能效率高且行為可預測。

  2. 同時增加剛度與消能能力 BRB 配置後顯著提升結構的側向剛度，減小層間位移（drift），對位移敏感的補強目標效果直接，適合需要增加整體勁度的既有建築補強。

  3. 施工簡單、造價合理 以標準鋼材製造，加工製作技術成熟，不需特殊液壓或密封系統，施工精度要求相對較低，補強工期短。

  4. 力學行為易於分析 遲滯模型為雙線性，參數（初始勁度 $k_o$、降伏力 $F_y$、後降伏勁度比 α）明確，可直接用靜力彈塑性分析（Pushover）或非線性時間歷時分析模擬，設計驗算可靠。

缺點：

  1. 提高側向剛度 → 結構週期縮短 → 可能增加地震力 BRB 增加剛度的同時，可能使結構自然週期縮短，若週期落入設計反應譜的高加速度區間，反而增大作用於結構的地震力，需重新核核梁柱承載力。

  2. 大地震後 BRB 可能需要更換 芯材降伏後累積的塑性應變有上限（低周疲勞），強震後需逐一檢查是否已損傷，必要時更換，震後恢復能力相對較差。

  3. 對「速度型」地震效果較有限 BRB 的消能與位移有關（遲滯面積 = 力 × 位移），對近斷層的速度脈衝型地震（高速度、較小位移），消能效果不如速度型阻尼器。

  4. 增加相鄰構材的軸力 BRB 以斜撐形式安裝，其軸力需透過梁柱節點傳遞，可能造成既有梁柱的軸力大幅增加，需驗核承載力，補強工程較複雜。

(B) 液態黏滯消能元件（Viscous Fluid Damper）

消能機制： 液態黏滯阻尼器由活塞在充滿矽油的缸體中往復運動，阻尼力：

$$F_d = C \cdot |v|^\alpha \cdot \text{sgn}(v), \quad \alpha \approx 0.3 \sim 1.0$$

阻尼力在速度最大時最大，在位移最大時接近零（速度為零），力-位移關係為橢圓形遲滯迴圈。

優點：

  1. 不增加結構側向剛度，不改變週期 阻尼力純粹依賴速度，不產生額外彈性勁度（線性黏滯阻尼的勁度貢獻為零），因此結構週期不縮短，不引入額外的地震慣性力。這是相對於 BRB 最顯著的優勢。

  2. 大幅增加等效阻尼比，廣頻消能 液態黏滯阻尼器可在寬廣頻率範圍內有效消能，對各種週期的地震（包括高頻、低頻）均有效，特別適合高層建築（多個振態的影響都能抑制）。

  3. 阻尼力與彈性力正交（差 90°），對梁柱的額外力需求低 在位移最大時，阻尼力接近零，梁柱的彈性恢復力已足夠；在速度最大時，阻尼力最大，但位移（和彈性力）較小。兩種力不同時達峰值，整體對結構的衝擊較和緩。

  4. 震後不需更換（不發生材料損傷） 黏滯阻尼器在正常使用條件下不發生材料降伏或疲勞，震後功能保全率高，適合需要「立即修復後使用（Immediate Occupancy）」的重要設施補強。

缺點：

  1. 製造成本高 液壓缸、密封系統及特殊矽油的製造精度要求高，成本遠高於 BRB，補強預算壓力較大。

  2. 需定期維護，密封件可能老化 液壓密封件（O 形環）隨時間老化可能發生洩漏，需定期檢查維護，對既有建築的長期維護管理增加負擔。

  3. 溫度效應 矽油黏度隨溫度升高而降低，導致阻尼力減弱；規範設計需考慮溫度修正（最不利溫度下的阻尼係數），增加設計複雜度。

  4. 分析複雜度高 速度型元件使結構分析從線性變為非線性（速度相依）或需要等值線性化處理，分析工作量增加；且需考慮「三種變位情況」包絡設計（詳見題(二)），設計驗算程序較繁複。

  5. 不提供側向剛度 若補強目標含括「減小層間位移」，純黏滯阻尼器的效果有限（不增加剛度），往往需與其他剛度補強措施（如剪力牆）並用。

總結對比（考場快速版）：

BRB 液態黏滯阻尼器
消能機制 鋼材降伏（位移型） 黏滯流體（速度型）
剛度影響 顯著增加（縮短週期） 無（週期不變）
阻尼比提升 中等 高
成本 低～中 高
維護 低 定期檢查
震後恢復 需檢查更換 良好
適用目標 需增加剛度+消能 僅需增加阻尼

題(二)（10分）：為何速度型元件需考慮三種變位情況？

核心物理原因：速度型阻尼器的力與位移不同相

對於位移型元件（如 BRB）： $$F_{\text{BRB}} \propto u(t) \quad \Rightarrow \quad \text{阻尼力在最大位移時最大}$$

對於速度型元件（如液態黏滯阻尼器）： $$F_d(t) = C|v(t)|^\alpha \propto |\dot{u}(t)|^\alpha$$

在諧和運動 $u(t) = U \sin(\omega t)$ 下：

$$\dot{u}(t) = U\omega \cos(\omega t)$$

位移與速度相差 90°，即：

  • 位移最大時（$\sin = 1$）→ $\cos = 0$ → 速度 = 0 → 阻尼力 = 0
  • 速度最大時（$\cos = 1$）→ $\sin = 0$ → 位移 ≈ 0 → 彈性力 ≈ 0

因此，最大位移時刻的結構內力組成 ≠ 最大速度時刻的結構內力組成。

三種情況的物理意義

情況一：最大變位情況（Δ_D，Maximum Displacement State）

量 狀態
層間位移 最大
速度 接近 0
阻尼器出力 接近 0（速度型阻尼器）
構材彈性變形力 最大
控制構材 梁、柱的彈性變形相關力（彎矩、剪力）

此情況控制對位移（變形）敏感的構材設計，尤其是梁柱接頭的彎矩需求。

情況二：最大速度情況（V_D，Maximum Velocity State）

量 狀態
層間位移 接近 0（或較小）
速度 最大
阻尼器出力 最大
慣性力 中等
控制構材 阻尼器連接元件（連接板、錨定螺栓、局部梁柱）

阻尼器的連接節點在最大速度時受力最大，若僅用最大位移情況設計，連接元件的設計力會嚴重低估——這是最常被忽略的設計控制情況。

情況三：最大加速度情況（A_D，Maximum Acceleration State）

量 狀態
加速度 最大
慣性力（F = mü） 最大
來源 主要來自高階模態（高頻振態）
控制構材 樓板、樓板連接、上層輕構件（對加速度敏感的設備）

在 MDOF 系統中，各模態的峰值位移、速度、加速度不同時發生。高階振態的加速度貢獻在特定時刻可能超過前兩種情況，對樓板慣性力的計算特別重要。

MDOF 系統中三情況的必要性

對於多自由度（MDOF）結構加裝速度型阻尼器：

  1. 各振態的相位不同：第一振態的最大位移時刻，高階振態可能正處於速度最大或加速度最大的狀態
  2. 非比例阻尼：速度型阻尼器通常造成非比例阻尼矩陣（$[C]$ 不與 $[M]$、$[K]$ 共對角化），振態之間存在耦合，各模態的時域反應不能簡單疊加
  3. 等值線性分析的包絡需求：等值線性分析以等效阻尼比近似非線性阻尼行為，其結果是「統計平均」而非「時域最大值」。三種情況的包絡設計是對此近似誤差的補償

結論：

$$\boxed{\text{速度型阻尼力與彈性力不同相（差 90°），三時刻的控制內力組成根本不同；}}$$ $$\boxed{\text{規範要求三情況包絡設計，確保所有構材在各控制時刻均不超出承載力}}$$

實務上，三種情況的關鍵控制對象：

情況 主要控制對象
最大變位 梁柱彎矩、層間位移
最大速度 阻尼器接頭、連結板、錨定元件
最大加速度 樓板慣性力、加速度敏感設備及其連接

三者取最大值進行設計，方能確保整體結構系統（含阻尼器連接節點）在地震全程的安全性。

5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

5.1 BRB 與液態黏滯阻尼器的組合使用

實務補強工程中，兩者可搭配使用：

  • 液態黏滯阻尼器：提供大量等效阻尼（降低加速度反應）
  • BRB：提供側向剛度（控制位移）

如此可在不過度縮短週期的前提下同時控制加速度與位移，達到最佳補強效果。台灣部分高層建築補強採此混合策略。

5.2 α 值對液態黏滯阻尼器三情況影響

當 $\alpha < 1$（非線性黏滯阻尼器）時： $$F_d = C|v|^\alpha, \quad \alpha < 1$$

阻尼力對速度的增長率遞減，等效阻尼比隨振幅增大而減小——即大地震時提供相對較少的額外阻尼力增量（具有限力特性），可避免連接節點在大震下超載。但 $\alpha < 1$ 使動力分析更複雜，三種情況設計更不可或缺。

5.3 位移型元件（BRB）是否需要三種情況？

不需要。BRB 的阻尼力與位移同相（遲滯迴圈的寬度決定於位移），最大內力出現在最大位移時刻，等值線性化後可以單一情況設計。三種情況是速度型元件特有的規範要求，正因為其力-位移相位差造成的特殊複雜性。

5.4 考場答題建議

  • 題(一)：BRB 與液態黏滯阻尼器各列 3～4 條優缺點，並在開頭先說明消能機制差異（一句話），再進入優缺點分析
  • 題(二)：用「速度型阻尼力與位移差 90°」這個物理核心展開，對三種情況各說明其「控制什麼力、對應什麼構材」，邏輯自然清晰
  • 兩題均為論述題，不需計算，但可引用 $F_d = Cv^\alpha$ 增加精準性
